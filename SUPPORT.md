# Getting help

- **Questions / setup help / ideas:** use
  [GitHub Discussions](https://github.com/joshuashunk/reeve/discussions).
- **Bugs:** open an [issue](https://github.com/joshuashunk/reeve/issues/new/choose)
  using the bug template.
- **Security vulnerabilities:** report privately via the **Security** tab → *Report
  a vulnerability* (see [SECURITY.md](SECURITY.md)). Please don't file these as
  public issues.

Before asking, the [README](README.md) covers setup, and
[docs/](docs/) has architecture and design notes.

**Please don't share secrets** (API tokens, passwords, real hostnames/IPs) in
issues or discussions; redact them first.
