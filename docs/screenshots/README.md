# Screenshots

Drop PNGs here and they'll render in the project README. Suggested set
(referenced by the main README's Screenshots grid):

| File | Shows |
| --- | --- |
| `dashboard.png` | Server dashboard, nodes + guests |
| `guest.png` | Guest detail, charts + manage menu |
| `datacenter.png` | Datacenter, firewall / cluster / users |
| `agent.png` | AI Agent chat |
| `widgets.png` | Home Screen widgets |
| `menubar.png` | macOS menu bar |

## Capturing

- **Simulator:** run the app, then `xcrun simctl io booted screenshot dashboard.png`.
- **Device:** take a screenshot normally and AirDrop/sync it here.
- Capture against a throwaway server (or anonymise hostnames); don't include
  real IPs, tokens, or hostnames in committed images.
- Keep them reasonably sized (≤ ~1.5 MB each); a 1242-px-wide portrait is plenty.
